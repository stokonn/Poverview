# Security policy

## Reporting a vulnerability

Please do not report security vulnerabilities in public GitHub issues, discussions, or pull requests.

Use GitHub's private vulnerability reporting feature for this repository when it is enabled. If private vulnerability reporting is unavailable, contact the repository owner through a private channel linked from the [GitHub profile](https://github.com/stokonn) and ask for a secure way to share the report.

Include, where possible:

- A concise description of the affected component and security impact.
- Steps to reproduce or a minimal proof of concept that does not access other people's data.
- Relevant versions, commits, configuration, and sanitized logs.
- Any suggested mitigation.

Do not include real credentials, access tokens, private repository contents, or personal information in the report unless strictly necessary and shared through an appropriate private channel.

Please allow the maintainer reasonable time to investigate and coordinate a fix before public disclosure. No response-time or remediation-time SLA is currently offered.

## Supported versions

Poverview has not published an application release yet. Security fixes and supported-version commitments will be defined when versioned releases are available.

## Scope

Report vulnerabilities in this repository's code, documentation examples, or project-controlled infrastructure. Issues in third-party services should be reported to their respective maintainers.
