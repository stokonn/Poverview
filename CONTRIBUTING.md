# Contributing

Poverview is currently in its planning and foundation phase.

Before proposing substantial changes, read the product vision, requirements, architecture, and roadmap. For major scope or design changes, open an issue first.

Project principles:
- Keep the product local-first and useful without GitHub.
- Do not introduce mandatory cloud services.
- Keep Android read-only.
- Never run arbitrary build or test commands without explicit user configuration and consent.
- Never commit credentials, access tokens, private repository data, or personal information.
- Prefer small, reviewable changes with tests and clear documentation.

When reporting an issue, include the affected component, reproduction steps, expected and actual behavior, and relevant sanitized logs.

Pull requests should explain the problem, summarize the change, list validation performed, and identify compatibility or security implications.
